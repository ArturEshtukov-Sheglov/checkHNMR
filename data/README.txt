Put the PDF files to be checked here: Supporting Information files, or a PDF made from the
checkHNMR template (any file names). A Word file must first be saved as PDF.
Then double-click run_all.bat (Windows) or run "bash run_all.sh" (Linux, macOS).
The results appear in the folder results, next to this folder: for every PDF a Word report
checked_<file name>.docx and the tables.
The files in this folder are not uploaded anywhere and are not part of the repository.
